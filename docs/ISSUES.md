### R-016 — Agent panel webview landed (Round 2D)
**Source:** O-001 (Round 2D deliverable) + `02_ARCHITECTURE.md` §7 (v0.1-alpha demo script)
**Status:** RESOLVED in `src/ui/agentPanel.ts` (WebviewViewProvider) + `src/ui/webview/agentPanel.{html,css,js}` + `media/kovix-viewbar.svg` + `docs/04_DESIGN_SYSTEM.md`
**Evidence:**
- `WebviewViewProvider` registered via `registerAgentPanel()` in `extension.ts activate()`. Fixes R-008 (uses `WebviewViewProvider` not `openView`).
- The provider proxies `AgentLoopEvent`s from `AgentLoopService.runWithApprovedPlan()` to the webview via `postMessage`, translating each event type into the protocol documented in `agentPanel.js`. Translation is unit-tested in `test/unit/ui/agentPanel.test.ts` (27 tests).
- The webview HTML is generated by the provider with a strict CSP (`default-src 'none'`, nonce-protected script tag). Asset URIs (`agentPanel.css`, `agentPanel.js`) are rewritten via `webview.asWebviewUri()`.
- The webview JS is vanilla (no React, no Tailwind, no CDN) per D-010. Implements: streaming token display, tool call cards (collapsible), plan approval card with autonomy-mode select, milestone pause banner (Resume/Skip/Abort), pending changes inline section (Accept/Reject/View diff), input box with auto-grow + Stop button while running.
- The design system is documented in `docs/04_DESIGN_SYSTEM.md` (Material 3 dark-first per D-013). Light theme deferred to v1.0-beta.
- The activity bar icon (`media/kovix-viewbar.svg`) is a 24×24 SVG using `currentColor` so it adapts to the user's theme.
- The `kovix.openAgentPanel` command now calls `provider.focus()` instead of the old quick-pick stub.
- The `package.json` `views.when` clause typo (`! Kovix.disabled` with a space) was fixed to `!kovix.disabled`.
- All 279 tests pass (252 from Round 2C + 27 new agentPanel tests). Typecheck clean. esbuild bundle 153.2 KB (up from 127.5 KB). `npm audit` 0 vulnerabilities.

### R-009 — `commandBlocklist.ts` regex compilation failure (CRITICAL — found in test-audit)
**Source:** Round 2C security audit (Bug 1 in `SECURITY_AUDIT.md`)
**Status:** RESOLVED in `src/terminal/commandBlocklist.ts:52,75-93`
**Evidence:** The pattern `'del /s /q c:\\'` (single trailing backslash) compiled to an invalid regex. Fixed to `'del /s /q c:\\\\'`. Added try/catch around `new RegExp()` so a future malformed pattern can't disable the entire blocklist. Verified by `test/unit/terminal/commandBlocklist.test.ts` "blocks 'mkfs.ext4 /dev/sda1'" + 10 other tests that previously THREW.

### R-010 — OpenAI key regex excluded dashes (MEDIUM — found in test-audit)

**Source:** Round 2C security audit (recommendation #4)
**Status:** DEFERRED to v1.0

The multi-root branch in `workspaceGuard.ts:96-111` is already implemented and tested; the tool layer just doesn't use it. Single-root is correct for v0.1; multi-root upgrade is a tool-layer change with no security implications.
**Revisit:** v1.0 — when multi-root workspace support becomes a priority.
